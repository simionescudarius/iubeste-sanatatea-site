## 📁 Structură Fișiere

- `index.html` — Pagina de prezentare a comunității (pilonii de alimentație, ghiduri practice, link-uri către documentele legale și pagina de Facebook).
- `privacy.html` — Politica completă de confidențialitate (prelucrarea datelor, cookie-uri, integrare Meta/Facebook API, drepturi GDPR).
- `terms.html` — Termeni și condiții de utilizare cu disclaimer medical explicit (informații cu rol educativ, nu înlocuiesc consultul medical).
- `deletion.html` — Instrucțiuni pas cu pas pentru ștergerea datelor utilizatorilor conform cerințelor Meta.
- `.nojekyll` — Dezactivează procesarea Jekyll pentru servire statică optimă pe GitHub Pages.
